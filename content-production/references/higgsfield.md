# Optional Higgsfield route

Use only when the content/task benefits from its tools or the user requests it. This skill requires neither a Higgsfield subscription nor a Claude account. Guidance reviewed on 2026-10-27; refresh the actual service catalog, account entitlements and prices before a new workflow.

## Access and capabilities

Discover connected Higgsfield tools/plugins first. An available catalog listing is not an installed/connected integration. If the service is connected and sufficient, prefer its purpose-built tools. Read their real schemas, account/project context, generation/edit modes, allowed references, limits and output contract. Do not make up tool names from website slash commands.

The website, a connector/MCP workflow and the developer API are distinct access routes. Higgsfield documents Claude integration through `https://mcp.higgsfield.ai/mcp`; this is an official connection reference, not a command to add it automatically. In a host supporting plugins/connectors, use its supported installation/auth flow only when requested/authorized. Browser use must follow the current host's rules. Do not expose credentials or paste keys into scripts committed to the project.

Higgsfield documents cinematic direction/reference workflows, image/video generation and Marketing Studio product creatives. Content Factory can assemble script, generated scenes, voiceover and edit for supported formats. Claude can direct a connected workflow while underlying models/tools generate the media. Verify which features and language/audio/reference controls exist on the chosen route; website documentation does not prove MCP/API parity.

## Production flow

Start with audience/offer, asset roles and storyboard. Choose a supported image/video/edit model for the actual shot, references, motion, duration, aspect and audio needs. Preserve identity/product details across shots using supported reference controls; do not assume a model can keep exact logos or text. For a real product demo, use real captures for factual behavior and reserve generated scenes for an appropriately identified concept/B-roll.

Estimate a bounded sample and total/revision budget using live prices. A website plan does not include API usage automatically: Higgsfield documents API billing as separate. Confirm the chosen entry point's credits/entitlements; do not assume "unlimited" or trial claims apply across tools. Generic permission to discuss paid options is not a purchase/top-up or an unlimited retry budget.

Reuse existing authorization for the requested paid work. Track jobs, selected assets and costs when available; revise individual failed shots or narration where supported. A timeout or missing response can leave a billable job running: reconcile its actual status before resubmitting, and do not invent refunds/credits. Stop before exceeding the agreed bound or making a new unapproved charge. Do not switch the user's explicitly chosen provider/model silently.

Retrieve the actual output, retain selected media in the workspace, inspect it against the brief and perform edit/export QA. Report queued/running, completed generation, downloaded/rendered final, reviewed and published as separate states. A preview URL or agent narrative is not a delivered video. Do not claim the integration works from reading documentation or selecting a model name.

If unavailable, continue with tool-independent script/shot prompts, an available direct generator, or local editing/code motion that meets the request. State the concrete missing connection/tool without calling that an equivalent finished asset. Do not silently install Higgsfield, buy credits, or upload private footage.
