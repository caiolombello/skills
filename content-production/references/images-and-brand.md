# Images, thumbnails, and asset consistency

Use the runtime's actual image-generation workflow for raster creation/editing. In Codex, read `imagegen` and prefer its built-in tool; do not duplicate its SDK, change its model or move to CLI without the authorization its contract requires. No image needs to be generated merely to create this skill or discuss a concept.

## Define the asset

Identify purpose, placement/ratio, audience, product/subject, visual direction, exact text, supplied logo/fonts/palette, required clear space, export format and destination. Distinguish a new visual from an edit. For each attachment specify edit target, reference, or insert. Inspect an edit target before changing it through the required tool workflow.

For actual product promotion, preserve physical features, interface facts, colors, packaging and identity that matter. A conceptual scene can change setting or mood without inventing a feature or a customer result. Do not ask a model to guess a missing logo or reproduce it inaccurately. A style reference can guide composition, lighting or pacing without copying protected artwork.

## Direct and iterate

Write a production brief: purpose and composition, subject/action, environment, light/style, format, exact copy and important invariants. Avoid prompt stuffing. Keep user-authored text verbatim when required. Use one selected direction to align thumbnail, video inserts and other campaign assets; preserve references and selected versions instead of regenerating unrelated identities shot by shot.

Inspect the output: product/identity, typography, exact wording/numbers, unwanted extra logos, hands/geometry when relevant, clear space, contrast, crop and transparency. A model saying the image is correct is not inspection. If exact typography remains unreliable, use the permitted editing workflow or an authorized separate text-compositing step; do not silently change the wording or bypass an image tool restriction.

Use targeted revisions to the failed part. A small requested change should preserve approved composition and invariants. Keep originals and save selected finals in the actual project/workspace before consuming them. Follow the image tool's save/export contract; do not invent a destination parameter or leave a production reference pointing only to a transient preview.

## Rights and delivery

Keep the origin and allowed use of supplied/generated/stock assets available when relevant to commercialization. Music, likenesses, brand assets, fonts and stock have independent terms. A paid tool plan is not proof that all inputs or outputs are cleared.

Deliver a real raster file when the request calls for one. A mockup, HTML representation or prompt is not the requested photo/banner. For an asset intended to post or use elsewhere, provide its actual PNG/JPEG/WebP path as appropriate; do not substitute an inline visualization renderer. An image selected for a video still needs actual timeline placement and export.
